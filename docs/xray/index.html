Commit X-ray · v0

Which commit will break production?

A model that scores every code change for bug risk the moment it's pushed, weeks before the bug is found.

Try it on real commits

Real commits from Apache Kafka, Hive, Flink, HBase… from 2017–2019, years the model never saw. Tap one, read the risk, then reveal what really happened. Includes misses and false alarms too.

How it works

  1. Every commit becomes 13 numbers: size, files and subsystems touched, how spread-out it is, the files' past change history, the author's experience in that area.
  2. Labels come from history itself: when a later "fix" commit lands, git blame traces the fixed lines back to the commit that introduced the bug (SZZ algorithm).
  3. Gradient boosting, written from scratch in NumPy: each round computes every commit's gradient and hessian, grows a tree with histogram splits, and sets each leaf to the Newton step −G/(H+λ).
  4. Explanations for free: each tree split hands its change in risk to the feature it used, so every score comes with its reasons.
